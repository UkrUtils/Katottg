# UkrUtils.Katottg

> English: [README.md](https://github.com/UkrUtils/Katottg/blob/main/README.md)

Бібліотека .NET для роботи з **Кодифікатором адміністративно-територіальних одиниць та територій
територіальних громад (КАТОТТГ)**, офіційним реєстром областей, районів, громад і населених пунктів
України: пошук за назвою та адресою, ієрархія «область → район → громада → населений пункт → район
у місті», перевірка кодів, імпорт офіційного xlsx.

Сайт і документація: https://ukrutils.github.io/Katottg/uk/

- Працює одразу після встановлення: офіційні дані вбудовані в пакет (~360 КБ), мережа не потрібна.
- Без залежностей, дружня до AOT і trimming. Набір даних незмінний і безпечний для багатьох потоків.
- Вбудована редакція: **03.11.2026** (`KatottgDataset.Embedded.Edition`), 31 751 запис.

| Пакет | Для чого |
|---|---|
| `UkrUtils.Katottg` | моделі, пошук, ієрархія, вбудовані дані |
| `UkrUtils.Katottg.Import` | розбір офіційного xlsx (`KatottgSheetParser`) |
| `UkrUtils.Katottg.Tool` | CLI `katottg`: `import`, `build-snapshot`, `search` |

```bash
dotnet add package UkrUtils.Katottg
```

## Швидкий старт

```csharp
using UkrUtils.Katottg;

var katottg = KatottgDataset.Embedded;          // ліниво завантажується один раз (~12 мс)

// За кодом
var unit = katottg.Find(KatottgCode.Parse("UA01020010010075540"));
Console.WriteLine(unit!.FullName);
// с. Андріївка, Андріївська громада, Бахчисарайський р-н, АР Крим

// За назвою або адресою
var hit = katottg.Search("смт Андріївка, Бердянський р-н, Запорізька обл.").Best!;
Console.WriteLine($"{hit.Unit.Code} {hit.Unit.FullName}");
// UA23020030010042079 смт Андріївка, Андріївська громада, Бердянський р-н, Запорізька обл.
```

## П’ять правил, які варто знати одразу

1. **Ключ — код (`UA` + 17 цифр), ніколи не назва.** «Іванівка» трапляється 120 разів, а однакові
   назви є навіть в одній громаді.
2. **Зберігайте лише код найнижчого рівня.** Батьків дає `Find(code)`; у SQL фільтруйте за префіксом
   (`LIKE 'UA2302%'`).
3. **Не розбирайте адреси самостійно.** Передайте рядок у `Search(...)`: він сам упорається з
   маркерами категорій, комами, вулицями, поштовими індексами, апострофами й регістром.
4. **Рівнів ієрархії може не бути.** Київ і Севастополь не мають району й громади; Прип’ять і
   Чорнобиль лежать прямо під областю. `District`, `Community` та інші можуть дорівнювати `null`.
5. **Показуйте людям категорію.** Використовуйте `DisplayName` («с. Андріївка») або `FullName`, а не
   `Name`.

## AI-агенти у вашому проєкті

Агенти (Claude Code, Copilot, Cursor, Codex…) читають `AGENTS.md` / `CLAUDE.md` **вашого**
репозиторію, але не документацію всередині NuGet-пакетів. Щоб агент правильно працював із КАТОТТГ,
додайте у свій `AGENTS.md`:

```markdown
## КАТОТТГ (UkrUtils.Katottg)

Для кодів адміністративно-територіальних одиниць України використовуй NuGet-пакет UkrUtils.Katottg.
Перед тим як писати код із ним, прочитай посібник для агентів (англійською):
- локально: ~/.nuget/packages/ukrutils.katottg/<версія>/AgentGuide.md (версія — з .csproj);
- онлайн: https://github.com/UkrUtils/Katottg/blob/main/Docs/AgentGuide.md

Головне: ключ — код (UA + 17 цифр), а не назва; у БД зберігай лише код найнижчого рівня;
адреси з тексту передавай у KatottgDataset.Embedded.Search(...); рівні ієрархії можуть бути null.
```

Посібник лежить у корені кожного пакета (`AgentGuide.md`, англійською), тож агент може прочитати
його офлайн, саме для встановленої версії. Ключові правила продубльовано в XML-документації типів
(`KatottgDataset`, `KatottgCode`), яку агенти бачать через IntelliSense або декомпіляцію.

## Дані та ліцензія

Дані взято з офіційного Кодифікатора, затвердженого наказом Мінрегіону від 26.11.2020 № 290
(в редакції наказу від 12.01.2021 № 3). Джерело — сайт Міністерства розвитку громад та територій
України. Вихідні xlsx-файли зберігаються в
[`OfficialData/`](https://github.com/UkrUtils/Katottg/tree/main/OfficialData). Код бібліотеки
поширюється за ліцензією MIT ([LICENSE](https://github.com/UkrUtils/Katottg/blob/main/LICENSE)).
